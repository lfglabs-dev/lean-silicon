# What “optimal” means in this project

Unqualified global-minimum claims are not meaningful for an ASIC. Gate count,
cycle count, clock period, state, I/O width, cell library, fan-in, and external
services trade against each other. This project therefore states every bound
inside an explicit model.

## Exact streaming-cycle bounds

The Lean file `Optimality.lean` proves the arithmetic lower bounds.

### One arbitrary word

An 8-bit input lane carries at most eight bits per accepted beat. Any protocol
that receives an arbitrary 128-bit value therefore needs at least 16 accepted
beats.

### XOR

Model:

- one command beat;
- one 8-bit input lane;
- both arbitrary 128-bit operands arrive externally;
- corresponding input bytes are interleaved;
- each result byte is accepted atomically with its B byte.

At least 32 payload beats are necessary:

```text
1 + 32 = 33 cycles
```

The RTL achieves 33 under no stalls. It cannot be faster in this model because
the input lane itself cannot carry the 256 operand bits in fewer beats.

### SET and NONZERO

SET returns each byte on the same beat that accepts it. NONZERO emits its answer
on the final input beat. Each therefore reaches:

```text
1 + 16 = 17 cycles
```

### Multiplication

Radix 1 model:

- one multiplier bit can be consumed per processing beat;
- A loads over the 8-bit lane;
- B is streamed LSB-first;
- result output begins after the last B bit;
- no stalls.

Lower bound:

```text
1 command + 16 A + 128 bit steps + 16 output = 161 cycles
```

The RTL achieves 161.

At radix 8, one B byte is consumed per processing beat, so the corresponding
protocol lower bound is:

```text
1 + 16 A + 16 B + 16 output = 49 cycles
```

## Exact source-level state count

The implemented radix-1 design has 273 explicit sequential bits:

```text
4 state + 4 byte index + 8 scratch + 1 fault + 128 shifted A + 128 accumulator
```

The 17-bit stream engine meets the direct lower bound implied by its declared
requirements: 11 phases, 16 positions, one saved arbitrary byte, and a sticky
fault flag. This is not a protocol-independent lower bound.

## Restricted gate model

The analytical report uses:

- two-input AND and XOR gates;
- single-output gates;
- wires and fanout free;
- the explicit digit-serial transition;
- no ROM or externally precomputed partial products.

### Streaming XOR byte

Eight independent output bits each equal `a_i xor b_i`. The lane-local
implementation uses eight XOR2 gates. Under the single-output, no-cross-lane
sharing model, fewer than eight cannot produce eight distinct nontrivial output
functions.

### `xtime`

GHASH reduction after a left shift changes bits 0, 1, 2, and 7 according
to the old top bit. Bit 0 is exactly the old carry and is therefore a wire;
only bits 1, 2, and 7 require XOR2 gates. The remaining outputs are wires.

`tools/exact_linear_xor.py` performs breadth-first exact synthesis over every
linear XOR2 network on the four relevant inputs. It rules out depths/gate
counts below three and emits a three-gate construction, so this bound does not
rely only on counting the three output lanes.

### Radix-1 multiplier transition

For every accumulator bit:

```text
acc_next[i] = acc[i] xor (a_shift[i] and multiplier_bit)
```

The direct network uses:

- 128 AND2 gates;
- 128 XOR2 gates;
- three XOR2 gates for `xtime`.

Total: **259 simple gates**, excluding control and registers.

This is minimum direct transition logic in the stated architecture family. It
is not a proof against every possible Boolean network or Sky130 compound-cell
mapping.

## Pareto frontier

Generated by `tools/design_space.py`:

| Radix | State bits | Direct gates | MUL cycles | Transaction cycles |
|---:|---:|---:|---:|---:|
| 1 | 273 | 259 | 128 | 161 |
| 2 | 273 | 518 | 64 | 97 |
| 4 | 273 | 1036 | 32 | 65 |
| 8 | 273 | 2072 | 16 | 49 |

Every point is nondominated in `(state, direct gates, latency)`. Radix 1 is the
minimum-direct-logic result; radix 8 is the minimum-latency result. Radix 2 and
4 are legitimate intermediate choices.

## Optimizations already applied

The current RTL is the result of repeated state/liveness and datapath passes:

1. use 32-bit addresses only in the future full core, not in the ALU proof
   boundary;
2. stream XOR/SET/NONZERO instead of retaining 128-bit words;
3. share one scratch byte across mutually exclusive operations;
4. load A directly into the shifted multiplicand;
5. stream B and replace the sub-bit counter with a sentinel;
6. remove the multiplier busy flag and let the parent phase control it;
7. destructively serialize the accumulator instead of selecting a result byte;
8. make output completion combinational, eliminating the result holding byte.

The explicit state fell from the first 423-bit sketch to 273 bits. More
aggressive reductions require changing a stated property, such as dropping the
sticky fault bit, resending A from the host, or changing the protocol.

## Claims deferred until EDA results exist

The following cannot be asserted yet:

- minimum Sky130 cell area;
- minimum routed tile count;
- maximum clock frequency;
- minimum energy per operation;
- globally minimum GF(2^128) Boolean circuit;
- complete ISA refinement.

Required evidence includes Yosys statistics, OpenLane placement/routing,
static timing, power estimation, and complete memory-controller proofs.
