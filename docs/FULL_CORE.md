# Full-core scope (superseded)

This former autonomous-core integration proposal is superseded by LSC-1.
There is no full autonomous core in this repository's active roadmap. LSC-1
uses host-prepared packets and keeps program/VM memory, pointer resolution,
deferred equality, inversion assistance, BLAKE3, traces, and proofs on the Mac.
See [ROADMAP](ROADMAP.md) and [LSC1_PROTOCOL](LSC1_PROTOCOL.md).
