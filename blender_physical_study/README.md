# leanSilicon Blender physical study

This autonomous package generates a reproducible, conceptual Blender 4.x
visualization from the repository's real final Yosys/ABC generic-cell
inventory. It is a demo-only design study. It is **not GDS or P&R**, and makes
no floorplan, CTS, routing, timing, DRC, LVS, density, antenna, extraction, or
fabrication claim. The geometric rows, dimensions, pad ring, layer patterns,
power straps, and clock spine are deterministic visual abstractions—not
physical implementation results.

Every render permanently displays:
`CONCEPTUAL · SKY130-INFORMED · NOT GDS/P&R`.

## Reproduce

From the exact repository base
`618b39923862e660589cc6258e258783904b3861`, with Blender 4.2.9 LTS:

```sh
python3 -m unittest blender_physical_study/test_package.py
blender --background --factory-startup --python blender_physical_study/generate.py -- --profile preview
blender --background --factory-startup --python blender_physical_study/generate.py -- --profile all
python3 blender_physical_study/make_contact_sheet.py
python3 blender_physical_study/write_provenance.py
python3 blender_physical_study/write_checksums.py
python3 blender_physical_study/verify.py
blender --background blender_physical_study/artifacts/lean_silicon_physical_study.blend --python-expr \
  "import bpy; assert bpy.context.scene['inventory_total'] == 167885; print('blend-ok')"
```

The generator makes one mesh point per logical cell and uses Geometry Nodes
linked instances for bounded file size. Cell order is the sorted Yosys cell
type followed by ordinal, laid into alternating 410-column rows. Thus all
167,885 cells and type proportions are exact, while placement is explicitly
not inferred. The input is the final flattened statistic block in
`results/m2-20260725T022000Z/m2-controller-synthesis.log`; its SHA-256 is
recorded in `provenance.json`.

## Outputs and boundaries

`artifacts/` contains the `.blend`, 4K hero, exploded, top, close-up,
transparent hero, and contact sheet. An optional 10-second 1080p/24fps orbit
is generated by adding `--animation`; it is not committed because measured
single-frame runtime projected beyond the bounded rendering window. `VISUAL_QA.md`
records the preview/inspection iterations. `SHA256SUMS` covers package
artifacts. Blender's Eevee Next renderer is used for bounded CPU runtime.

The synthesis evidence is a Yosys generic primitive inventory after ABC, not a
SKY130 standard-cell library mapping and not a connectivity-bearing physical
netlist. “SKY130-informed” refers only to the conceptual layer vocabulary and
standard-cell visual language. No hardware was built; do not merge or release
this demo package.
